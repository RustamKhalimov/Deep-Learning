Repository Structure
Final Project
The Final/ folder contains the hand gesture image classification project and its results.
- gesture_dataset/ — dataset used for hand gesture classification.
- Final_DL.ipynb — project notebook.
- best_gesture_model.pth — saved PyTorch model.
- training_curves.png — training performance curves.
- confusion_matrix.png — confusion matrix visualization.
- misclassified.png — examples of misclassified images.
- DL_Final_Report.docx — final project report.
